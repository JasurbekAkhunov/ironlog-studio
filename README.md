# IRONLOG Studio

Бесплатный дневник силовых тренировок для Android. Поддержка автора рекламой добровольная.

[Скачать последнюю подписанную версию](https://github.com/JasurbekAkhunov/ironlog-studio/releases/latest)

Выберите файл APK в разделе Assets и установите его поверх текущей версии IRONLOG Studio. Новые версии появляются в разделе Releases. История тренировок в облаке доступна после входа в тот же аккаунт.
